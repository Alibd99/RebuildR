# Project brief

Working title (from the provided brief):
**Designing on-site material banks for construction reuse: a scalable system approach using digital platforms and AI**

## Context (high level)

RebuildR is developing scalable solutions for reuse of building materials. The current solution combines a digital marketplace for reused building materials with physical hubs for handling and distribution.

## Why on-site reuse

Reuse at **active construction sites** can unlock large volumes of reusable materials, but practical constraints and logistics make it hard to scale (e.g., site access restrictions, time/resource constraints for transport, and the need for traceability).

## Problem statement (initial)

Create a concept/system for **on-site material banks** that:

1. Supports on-site collection under safety/accessibility constraints
2. Enables sale and/or rental flows (including temporary “borrow/return” instead of permanent transfer)
3. Minimizes operational overhead for construction companies while maintaining traceability, documentation, and control

## Open questions

- What “material bank” means operationally (storage, cataloging, ownership, liability)
- Data model for items/materials (IDs, condition, quantity, provenance, photos)
- Roles and permissions (site manager, subcontractors, hub operators, buyers/renters)
- Required integrations (RebuildR marketplace, inventory systems, identity/access)
- Compliance (safety, privacy, procurement rules, reporting)

## Deliverables (to confirm)

- Requirement & stakeholder analysis
- Prototype (UX + data model + minimal backend, if needed)
- Evaluation with stakeholders and iteration plan
